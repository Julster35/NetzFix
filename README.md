# NetzFix

Open-data model of the German transmission grid comparing total system cost under one price zone + redispatch, bidding zones, and nodal pricing (base year 2024), with an interactive web twin. Research model, not an operational twin.

- Plan: [RESEARCH_PLAN.md](RESEARCH_PLAN.md)
- Research vault (Obsidian): [vault/00_Home.md](vault/00_Home.md)
- Setup: `uv sync`, `uv run pytest`. Copy `.env.example` to `.env` for API tokens.

Status: Milestone 0 (scaffold and design), 2026-11-03.
