# Brown Hoersch Schlachtberger 2018

## For future agent
The software paper for PyPSA, the modelling library NetzFix uses for all optimisations. Cite it for the tool; method details we rely on (power-flow formulation, duals) must be checked in it before they are stated in [[DC Power Flow]] or [[Nodal Pricing (LMP)]].

## Claims (`stated`, from the PDF)
- Abstract (p. 1): PyPSA is "a free software toolbox for simulating and optimising modern electrical power systems over multiple periods", with models for conventional generators with unit commitment, variable renewables, storage, sector coupling and mixed AC/DC networks.

## Relevance
- Tool citation. The current library is PyPSA v1.4.0 (2026-10-09), much changed since 2018 ([[Prior Art]]).
