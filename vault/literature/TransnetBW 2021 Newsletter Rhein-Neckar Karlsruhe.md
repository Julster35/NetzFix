# TransnetBW 2021 Newsletter Rhein-Neckar Karlsruhe

## For future agent
A TransnetBW project newsletter (printed "05/2021"; the URL file name says 2022_06). It is held because it states that the **Großkraftwerk Mannheim (GKM) produces into the 220 kV level**, and that a new UW Mannheim will transform that to 380 kV in the future. This supports the model's attachment of GKM at a 220 kV bus ([[Validation]], 2026-11-05 network diagnosis).

## Claims (`stated`, p. 4)
- "muss ein neuer Netzverknüpfungspunkt am Großkraftwerk Mannheim (GKM) entstehen und an das 380-kV-Übertragungsnetz angeschlossen werden. Dieser Netzverknüpfungspunkt, das Umspannwerk Mannheim, wird zum einen den im GKM erzeugten Kraftwerksstrom von der 220-kV- auf die verlustärmere 380-kV-Spannungsebene transformieren"
- "durch zwei 380/220-kV-Transformatoren mit jeweils 1.100 MVA"
- Application for UW Mannheim submitted 19 April 2022 (the text is in the newsletter despite the 05/2021 footer; date mismatch noted).

## Use
- GKM's 2024 connection = 220 kV (the new UW Mannheim G380 is part of the project with target commissioning 2031: [[TransnetBW 2025 Projektbroschuere Weinheim-Karlsruhe]]). `high` (stated plan + target date after 2024).
